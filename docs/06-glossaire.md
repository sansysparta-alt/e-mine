# e-mine · Glossaire

| Terme | Sens |
|---|---|
| CPDM / Guichet unique | Réception des dossiers et recevabilité |
| DNM / DNG | Direction nationale des Mines / de la Géologie |
| BNE | Bureau national d'expertise (certificats d'expertise des lots) |
| SOGUIPAMI, ANAIM | Organismes sous tutelle (participations, infrastructures) |
| ITIE | Initiative pour la transparence des industries extractives |
| FODEL | Fonds de développement économique local |
| EIES | Étude d'impact environnemental et social |
| NIF / RCCM | Numéro d'identification fiscale / Registre du commerce |
| GNF | Franc guinéen |
| PRC, PRE, PEX, CAR, CES | Permis de reconnaissance, de recherche, d'exploitation, autorisation de carrière, cession |
| AEA, COR, AGC | Exploitation artisanale, carte d'orpailleur, agrément de comptoir |
| CEX, AEX, KIM | Certificat d'expertise, autorisation d'exportation, conformité export diamant |
| EXC, CCC, ARF, PME | Extrait de cadastre, copie certifiée conforme, attestation de redevances, agrément PME |
| Frais / Droits | 1er paiement (condition de recevabilité) / 2e paiement (condition de délivrance) |
| Port / adaptateur | Interface métier vers un système externe (ArcGIS, TrésorPay, HSM, SMS) et son implémentation (simulateur ou réelle) |
| BFF | Back-end for front-end : le serveur Next.js qui garde les jetons et appelle l'API |
| RLS | Row Level Security : filtrage des lignes par PostgreSQL selon l'utilisateur |
| DoR / DoD | Definition of Ready / Definition of Done (voir `04-plan-des-sprints.md`) |
